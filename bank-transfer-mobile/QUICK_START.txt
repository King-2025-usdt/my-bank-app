🚀 خطوات التثبيت:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. استخراج الملف:
   unzip bank-transfer-mobile.zip
   cd bank-transfer-mobile

2. تثبيت المكتبات:
   npm install

3. تشغيل التطبيق:
   
   ✓ على الويب (للاختبار السريع):
     npm run web
   
   ✓ على محاكي Android:
     npm run android
   
   ✓ على محاكي iOS (macOS فقط):
     npm run ios
   
   ✓ على هاتفك الفعلي:
     - ثبت تطبيق "Expo Go" من متجر التطبيقات
     - اكتب: npx expo start
     - امسح رمز QR بهاتفك

Q: التطبيق لا يعمل
A: جرب: npm install && npm start -- --clear

Q: خطأ في المكتبات
A: استخدم: npm install --legacy-peer-deps

Q: لا أستطيع الاتصال بالهاتف
A: تأكد من أن الهاتف والحاسوب على نفس الشبكة
