# تطبيق التحويل البنكي الدولي - مصرف الراجحي

تطبيق موبايل احترافي لمحاكاة عملية التحويل البنكي الدولي بأسلوب مصرف الراجحي.

## المميزات

✅ **واجهة عربية كاملة** - جميع النصوص والواجهة بالعربية  
✅ **4 خطوات للتحويل** - تدفق سلس وسهل الاستخدام  
✅ **لوحة تحكم إدارية** - التحكم الكامل في الإعدادات والعمليات  
✅ **تصميم احترافي** - ألوان وتصميم يطابق مصرف الراجحي  
✅ **تخزين البيانات** - حفظ العمليات محلياً على الهاتف  
✅ **متوافق مع iOS و Android** - يعمل على جميع الهواتف الذكية  

## التثبيت

### المتطلبات
- Node.js و npm
- Expo CLI
- هاتف ذكي أو محاكي

### خطوات التثبيت

1. **استخراج الملف المضغوط:**
```bash
unzip bank-transfer-mobile.zip
cd bank-transfer-mobile
```

2. **تثبيت المكتبات:**
```bash
npm install
```

3. **تشغيل التطبيق:**

**على محاكي Android:**
```bash
npm run android
```

**على محاكي iOS (macOS فقط):**
```bash
npm run ios
```

**على الويب (للاختبار السريع):**
```bash
npm run web
```

4. **تشغيل على هاتفك الفعلي:**
- ثبت تطبيق Expo Go من متجر التطبيقات
- قم بتشغيل: `npx expo start`
- امسح رمز QR بهاتفك

## الخطوات الأربع

### الخطوة 1: بيانات المستفيد
- أدخل اسم المستفيد
- أدخل اسم البنك
- أدخل رقم الحساب أو IBAN

### الخطوة 2: إدخال المبلغ
- اختر العملة (SAR, USD, EUR, GBP, AED)
- أدخل المبلغ المراد تحويله
- اختر غرض التحويل

### الخطوة 3: تأكيد البيانات
- راجع ملخص التحويل
- تحقق من البيانات
- أكد العملية

### الخطوة 4: النتيجة
- عرض نتيجة العملية (نجاح/فشل)
- حفظ العملية في السجل

## لوحة التحكم الإدارية

اضغط على أيقونة الإشعارات في الزاوية العلوية اليسرى وأدخل كلمة المرور: **1234**

## التطوير

### إضافة ميزات جديدة
1. عدّل الملفات في مجلد `app/`
2. التطبيق سيعيد تحميل تلقائياً
3. اختبر التغييرات على الفور

### بناء تطبيق للإصدار

**Android:**
```bash
eas build --platform android
```

**iOS:**
```bash
eas build --platform ios
```

## استكشاف الأخطاء

### التطبيق لا يعمل
- تأكد من تثبيت جميع المكتبات: `npm install`
- امسح ذاكرة التخزين المؤقتة: `npm start -- --clear`

### مشاكل في الاتصال
- تأكد من اتصالك بالإنترنت
- أعد تشغيل محاكي الهاتف
